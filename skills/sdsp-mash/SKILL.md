# sdsp-mash — мэшапы и сайферы

Engine: `tools/sdsp-mash` in `/Users/rustam/Music/1music/superduper-dsp`
(`cargo run --release -p sdsp-mash -- mash.toml out.wav`). Pattern of sdsp-chain:
TOML stages, per-stage LUFS/dBTP. User confirmed it sounds better than ffmpeg gluing.

## Pipeline

1. **Подбор пары/куплетов** (правила решают всё):
   - BPM: 1:1, 2:1 (half-time) или стретч ≤ ±8% — тянуть ВСЕГДА бит, вокал священен (узнаваемость).
   - Ключи: для читки почти неважно; для напевных хуков — соседи по Camelot (±1, A↔B).
   - Замер: `sdsp-mash analyze <wav>` (v1; точный BPM + анти-полутемп x2/x0.5) или `~/.claude/skills/music-teka/keybpm.py` (BPM+key+Camelot).
2. **Стемы**: `demucs --two-stems=vocals` для вокала; полный 4-stem для бита (drums/bass/other). venv с demucs: scratchpad `kx` (или поставить заново: pip install demucs).
3. **mash.toml**: `bpm` грида; `[[track]]` role=beat-drums|beat-bass|beat-other|vocal, `offset_beats`, `start_sec/len_sec` (вырез куплета), `gain_db`, vocal: `highpass_hz`+компрессор (v1), `auto_align=true` (v1, фазовый снап по кросс-корреляции онсетов); `[duck]` — дакается ТОЛЬКО beat-other (бас/драмы не трогать — иначе «низ пропал»); `[intro_sweep]`; `[[master]]` eq→compressor→limiter.
4. **Рендер** → WAV → mp3 (`ffmpeg -q:a 0`) → в `~/Music/DJ/Sets/AI Mashups/`.

## Сайфер (куплеты из 2-3 песен)

- Несколько `[[track]] role="vocal"` с разными offset_beats (А такт 8, Б такт 40…), каждому свой вырез/гейн/FX.
- Ограничение BPM действует посегментно, если биты меняются между куплетами.
- Переходы бит→бит (v2 roadmap: `[[section]]` transition=): bass_swap (8-16 тактов верхами, бас одним движением), filter_sweep, breakdown (бит глохнет 1-2 такта, вокал акапельно, новый бит дропом на первую строку), drop (билд-ап — снейр-ролл/райзер/фильтр вверх 4-8 тактов — и новый бит бьёт дропом на пике; самый клубный), cut/pause (полная тишина 1-2 доли, «стоп-тайм» — дешёвый и мощный, новый бит с первой доли), fade_except (всё затихает КРОМЕ одного элемента — вокал/хэты/мелодия живёт соло 2-4 такта, новый бит подхватывает под него; параметр keep=vocal|hats|melody).

## Уроки (пополнять!)

- Вокал на −3 LU ниже подложки, дакинг ratio 2-2.5 — иначе «вокал орёт, бит тонет».
- Мастер: eq (низ +1.5, воздух +2.5@7k) → comp 2:1 → limiter до −10.5 LUFS/−1 dBTP — клубная громкость; −13 LUFS воспринимается «глухо».
- «Всё как в бочке» = где-то остался закрытый lowpass. Проверять средним спектром против оригинала (semilogx FFT, полосы БАС/ГОЛОС).
- ffmpeg sendcmd: опция зовётся `frequency`, НЕ `freq` — команды фейлятся молча.
- Лимитер SuperDuper: param 0 = INPUT gain (не threshold!), 1 = Ceiling.
- djay кэширует файлы — после замены mp3 перетаскивать трек заново.
- Найденные пары: Агент×Jump Around (105.5=105.5), Организация×Firestarter (72.5=145/2), Агент↔SMBU один ключ 11B но темпы далеки.
- **Тайм-стретч (v1) = WSOLA, чистый Rust.** signalsmith-stretch/ssstretch — это C++ биндинги (bindgen+libclang+cc, 41 пакет) → отвергнуты ради герметичности workspace/Windows-CI. `tempo_ratio` только на бит-стемах (вокал валидатор отклоняет). **Направление: ratio = старый_bpm / новый_bpm** (142→145 = 0.979, короче/быстрее). Диапазон 0.25..4.0.
- **`auto_align` имеет гейт уверенности (corr ≥ 0.30).** Кросс-жанровый рэп-вокал против чужого бита даёт слабую онсет-корреляцию (~0.17-0.18) → сдвиг ОТКЛОНЯЕТСЯ, остаётся nominal (печатает «rejected (low corr) — kept nominal»). Снап работает когда вокал делит ритмику с битом (был на похожем бите); для чужих пар offset ставить руками. Окно поиска ±полтакта (±2 доли).
- **analyze анти-полутемп:** Firestarter читается как 71 (strength 0.78) / ×2=142 (0.59) — ÷2-кандидат бывает СИЛЬНЕЕ истинного темпа на four-on-floor. Брать ×2 для клубных битов. Всегда печатает ÷2 и ×2.
- **WAV на выходе — Float32 (fmt tag 3).** Python `wave` его не читает («unknown format: 3») — проверять `afinfo`/ffprobe, не питоном.
- **v2 эффекты (`[[fx]]`)**: `tape_stop` (ресемпл-рампа в ноль — финал), `beat_repeat` (статтер даунбита 1/2→1/4→1/8 перед сменой бита), `echo_out` (фидбек-делэй хвост), `kick_pump` (грид-сайдчейн-памп), `riser` (white-noise + открывающийся HP + t² свелл). Позиция `at_sec` (удобнее для мегамикса) или `at_beat`. Применяются к premaster ДО мастера.
- **v2 переходы (`[[section]] transition=`)**: `crossfade`/`bass_swap`/`filter_sweep` (equal-power overlap, бит след. секции въезжает fade_in, пред. хвостом fade_out), `drop` (хард-ин + авто-riser на xfade перед), `cut` (тишина-гэп xfade долей), `breakdown` (пред. бит гаснет, вокал/новый бит дропом), `fade_except keep=vocal|hats|melody` (всё гаснет кроме роли; hats→drums, melody→other). Пружина fade — в Stem (fade_in/fade_out сэмплы, equal-power sqrt).
- **v2 per-section темп** (`[[section]] bpm=`, `start_sec=`): каждая секция — свой темп-остров. Вокал НЕ стретчим → бит стретчим к темпу вокала (`tempo_ratio = native_beat_bpm / section_bpm`). Секции ставятся по `start_sec` на глобальный таймлайн, offset_beats внутри — в темпе секции. Так собирается мультивокальный сайфер (вокалы 110-161, биты Prodigy 130-149 — на одном гриде НЕ сходятся).
- **⚠️ WSOLA стретчит ПОЛНЫЙ декодированный стем ДО тримминга секции** → на бит-стемы ставить `len_sec` (≈длина секции+margin), иначе рендерит 6-минутный стем целиком и висит минуты. Обязательно.
- **v2 beats.rs/structure.rs портированы** из video-generator-agent (STFT-flux → темп с октав-коррекцией → грид-трекинг → downbeats + метр; self-similarity → секции). `analyze` теперь даёт точный BPM (Firestarter 142.11 vs CSV 141.5, БЕЗ half-tempo бага tempo.rs), downbeats (укладка вокала на 1-ю долю такта) и structure (verse cuts для сайфера, печатает start_sec/len_sec). tempo.rs остался фолбэком. `analyze` декодит FLAC/mp3 через ffmpeg (не только WAV).
- **Карта совместимости**: `scratchpad/compat_map.py` → `~/Music/DJ/Sets/_compat_map.md`. BPM из CSV (DJ-curated, надёжнее), Camelot — Krumhansl детект по файлу (CSV-ключи без моды). Скор 0.7·BPM-кратность + 0.3·Camelot. Топ-пары: Breathe×Хочу перемен (130=129.9, 1:1), Blade×Земфира Хочешь (133, 12A), Baby's Got A Temper×Detsl/Организация (106≈110).

- **Формат «мини-сеты» (юзер предпочёл вместо 1 мегамикса)**: несколько клипов по 2-3 мин, каждый = ОДИН бит Prodigy + 2-3 совместимых по темпу вокала. Готовые: SMBU×Сигма Бой (заставка-триггер), Baby's×Detsl×Организация (2 рэпера, один бит), Breathe×Кино (2 песни Кино). Кладём в `~/Music/DJ/Sets/*.mp3`.
- **Заставка-триггер (Дисней-клуб)**: `cut`-пауза → 5-8 сек заставки → `drop` обратно в бит. Заставка = отдельная секция с одним треком role=beat-drums (играет соло в своей секции), `len_sec`=8. Файлы: `~/Music/DJ/Misc/{Утиные истории,Чип и Дейл,Чёрный Плащ} - русская заставка (Дисней-клуб).mp3`.
- **`decode_any` (v2.1)**: `[[track]] path` теперь принимает mp3/flac напрямую (не только demucs-WAV) — не-WAV декодится через ffmpeg до 44.1k stereo. Так заставка/сырой трек кладётся в микс без предварительного demucs/конвертации.
- **«Один бит + N рэперов» = одна секция, несколько vocal-треков** с разными `offset_beats` (в темпе секции) — бит непрерывный, не надо beat-switch. Проще, чем секция-на-куплет.
- **⚠️ Баланс громкости секций**: разные части одного бита (интро vs дроп SMBU) отличаются на 5-7 дБ — если брать `start_sec` из разных мест, финал может быть громче куплетов. Держать `start_sec` бита в схожих по энергии зонах либо докручивать `gain_db` посекционно.
- **Проверка микса без ушей**: per-N-сек RMS-скан через ffmpeg+numpy (KX venv) → видно мёртвые зоны (баг echo_out ловился так: всё после точки = −180 дБ) и дисбаланс громкости.
- **⚠️ Замедление брейкбита >5-6% убивает грув** (Prodigy 136→123.5 = −9% звучал вяло). Решение — **встречный стретч**: тянуть бит И вокал к среднему гриду. Поп-вокал терпит **±5%** (валидатор `sdsp-mash` теперь пускает `tempo_ratio` у role=vocal при |ratio−1| ≤ 0.05, печатает warning; >5% — ошибка). Пример: SMBU 136→130 (−4.4%, грув цел) встречает Сигма Бой 125→130 (+3.9%). Направление вокала то же: `ratio = native/grid` (125/130 = 0.9628 = ускорение). Считать реальный BPM вокала через `analyze`, не из CSV.
- **v2.2 «жизнь» (Fred again): [pump] + [breath] + жирный бас + sub-drop.** `[pump]{depth_db,release_ms}` — kick_pump на ВЕСЬ микс, per-section (beat-zero = даунбит секции), «дышит» (проверка: autocorr огибающей на 1 бит >0.1). `[breath]{every_bars,len_bars,from_hz,to_hz}` — периодический rising HP (мини-билд без смены секции). Жирный бас: `saturate_db` на бас-стем (**tape_clip — НЕЧЁТНАЯ ф-ция → 3-я гармоника**, не 2-я; тестить 240Гц не 160) + `gain_db +2`. `sub_drop` — глиссандо-синус 55→45Гц пол-такта + noise-impact, **авто на каждом `drop`-переходе**, или `[[fx]] kind="sub_drop"`. hp_sweep-breath: rising HP тоньшит низ→снап назад.
- **v2.2 НЕ сделано (задескоплено, самое сложное):** vocal delay-throw (эхо последнего слога фразы — нужен onset-детект границ фраз) и vocal chops-текстура (нарезка+питч±3-5пт ресемплом). Реализовывать при следующем заходе — onset.rs уже есть для детекта пауз.
- **⚠️ v2.3 КРИТИЧНО: post-master leveler УБИВАЛ дропы/агрессию.** Симптом: FX не слышны, дроп «вялый». Измерено: leveler ON → дроп на −1.5дБ ТИШЕ интро (payoff мёртв); OFF → +2.5дБ выше. Причина: leveler тянул энергичную дроп-секцию вниз к медиане. **Фикс — DEADBAND 4.5дБ**: секция может быть до +4.5дБ над медианой БЕЗ аттенюации (это и есть payoff дропа), тамится только избыток сверх — грубые выбросы (+7дБ финал) чинятся, дропы дышат. Проверять «слышимость FX» метриками: drop-lift (RMS дроп−интро, должен быть +), pump-модуляция (размах огибающей в дроп-секции, было 30дБ), sub-drop peak — ДО и ПОСЛЕ leveler.
- **v2.3 delay-throw** (`delay_throw=true` на вокале или preset=wild): эхо последнего слова фразы в паузу (dotted-quarter 1.5 доли, fb 0.5). Детект фраз: RMS-огибающая 50Гц, loud→quiet с тишиной >0.4с = граница, min-spacing 2 доли. Аддитивно, dry не тронут.
- **v2.3 preset="wild"** = дефолт агрессии: авто [pump] depth6, [breath] каждые 8 тактов, сатурация баса (drive4), delay-throw на всех вокалах. Ставить в новые конфиги.
- **v2.3 агрессивный кусок вокала**: рэп-интро вялое (Организация 0-20с = −29дБ). Скан RMS 35с-окнами (шаг 4с), выбрать окно с RMS ≥ верхний квартиль — обычно поздний куплет/бридж (Организация: 124с). НЕ брать с start_sec=0/8.
- **v2.3 chops (#4b) задескоплено** — нарезка+chipmunk-питч. delay-throw (#4a) сделан.
- **v2.1 мягкие переходы (фидбек «швы тупые/резко/пустота»)**: КАЖДЫЙ шов секции получает lead-in/lead-out фейд (дефолт 1 доля, `lead_in_beats`/`lead_out_beats` на секцию) + микро-фейд-пол 22 мс на ВСЕ стемы (анти-щелчок, вкл. вокал). `cut` больше не хард-обрыв: авто beat_repeat последнего такта → lowpass-close за 1 долю (FilterSweep 16k→400) → echo-хвост fb 0.4 в паузу. `breakdown` гасит бит фильтром+фейдом за 2 доли (FilterSweep 16k→500). `drop` = авто beat_repeat lead-out + riser. Всё в `apply_section_transitions`.
- **Баланс секций (`balance_sections`, дефолт ON) — левелить ПОСЛЕ мастера, не по стемам!** Ключевой урок: raw-stem RMS и даже premaster-RMS баланс НЕ работают — мастер-лимитер нормализует плотные секции (голый громкий дроп) к потолку сильнее разреженных (куплет+вокал+дакинг), стирая любой pre-master gain. Единственно надёжно: `level_premaster_sections` меряет RMS секций в ГОТОВОМ (post-limiter) буфере и тянет громкие секции ВНИЗ к медиане (attenuation-only, сглаженная огибающая ≈0.3с, без клиппинга т.к. только вниз). Цена: −2..3 дБ общего LUFS (компенсировать — поднять `input` лимитера). Разрыв SMBU 6→0.6 дБ. Отключить: `balance_sections = false` (ДО `[[section]]`).
- **⚠️ микро-фейд-пол ломает импульс на сэмпле 0** в тестах — класть тест-импульс за 22 мс от начала стема.
- **⚠️ BPM-детектор УДВАИВАЛ темп (~103→206.72) — «октавная коррекция» в `beats.rs::estimate_tempo` игнорировала приору.** Симптом: два РАЗНЫХ трека ~103 BPM (Clubbed to Death, Poison) дали ИДЕНТИЧНЫЕ `206.72`. Механика: старый шаг «halve the lag if corr ≥ 50%» удваивал темп, удвоенный лаг упирался в `min_lag` (= верхняя граница `max_bpm=200` при hop 512/44.1k = лаг 25), а на границе парабола пропускается → выход = ровно `60·(44100/512)/25 = 206.71875` для ЛЮБОГО трека ~103. **Фикс:** октавное решение теперь prior-взвешенное — переоценивает семейство {½lag, lag, 2lag} той же лог-нормальной приорой (центр 120, σ 0.5), берёт максимум `corr·prior`. Держит истинные 100-103 на месте (приора 120 давит 206 сильнее, чем raw-corr тянет), но всё ещё спасает клубный трек, прочитанный на полутемпе (приора 120 перевешивает). Регресс-тест `test_ghost_offbeats_not_doubled` (клик 100/103/108 с призрачными восьмыми — именно они триггерили удвоение). **Кросс-чек librosa:** Clubbed 101.53↔103.36, Poison 104.07↔103.36, Spybreak 127.98↔129.20 — совпало.
- **Block Rockin' Beats 145.79 — НЕ баг** (librosa default-приора тоже даёт 143.55; выбор октавы легитимен, с приорой 100 упал бы к 107.7). `meter 6/4` у него и Spybreak — отдельная слабость `detect_meter` (variance-по-группам путает 4 и 6), на 4/4-грид мэшапа НЕ влияет. **Для рэп-мэшапа** нужный клубный темп может быть в ДРУГОЙ октаве, чем даёт детектор — сверяйся с librosa `start_bpm=100`, если хочешь «танцевальную» октаву.
- **Диагностика темпа:** `SDSP_DEBUG_TEMPO=1 sdsp-mash analyze <f>` печатает init-лаг, октавных кандидатов (bpm/corr/weighted) и финал. Референс librosa (venv `kx`): `beat.tempo(onset_envelope, start_bpm=…)` — сравнивай default-приору (~120) и start_bpm=100 чтобы увидеть октавную развилку.
- **Pingpong: пара вокалов с БЛИЗКИМ темпом = идеал (стретч ≈0).** Detsl «Кто там у руля» 109.84 + Oxxxymiron «Организация» 110.06 (замерено, не CSV) → грид 110, оба <0.2%. Агент читается 160.95 (октавная неоднозначность 3:2) — в паре хуже. Лучшие биты под ~110 рэп: **The Power 108.9** (+1.0%), **Jump Around 106.86** (+2.9%), **Poison 104.06** (@грид 108, +3.8% — единственный Prodigy-бит рядом с рэп-темпом). Отрендерены: `<Бит> × Detsl × Окси (pingpong).mp3` (−9.9…−11.3 LUFS, TP −1.0).
- **⚠️ `role_counts` не считал pingpong-`[[source]]`** → ложный варнинг «[duck] set but no vocal key» (дакинг РАБОТАЛ — pingpong-стемы это Role::Vocal). Пофикшено: source-вокалы считаются, если есть `[[phrase]]`/`[pingpong]`.
- **⚠️ Бит-стем с тихим интро** (The Power drums 0-8с = −63дБ, «I've got the power» — вокал, не в drums-стеме) → мёртвый воздух на старте. Триммить `start_sec` бита за начало грува (RMS-скан выхода ловит: интро <−40дБ = труп).
- **Цензурный хук через EDL + whisper.** Найти эксплицит/неэксплицит половины куплета — транскрибировать вокал-стем faster-whisper (venv `kx`, `base.en`/`small.en`, `word_timestamps=True`, нормализовать кусок `loudnorm=I=-14` — demucs-стем тихий/дисторшн). SMBU куплет «change my pitch up»(77.5с, неэксплицит) / «smack my bitch up»(251.3с, эксплицит; whisper слышит как «chase/smack my picture»). `[[source]]`+`[[phrase]]` режут по онсету и кидают на границы: неэксплицит 3× (интро/билд/после-дропа, gain −3…−5, `throw=true`), эксплицит 1× тихо (−9дБ, throw, на дроп-даунбит под sub-drop). **`end_sec` резать ДО онсета следующего слова** (78.88, перед «smack» на 78.92) — иначе цепляешь начало эксплицита. Источник для one-shot стабов — БЕЗ `tempo_ratio` (стретч всего файла сдвинул бы фразовые start_sec; 1.4с-стаб терпит 4.6% рассинхрон).
- **⚠️ whisper галлюцинирует «Thanks for watching» на обработанном/коротком миксе** — проверять цензуру транскрипцией ИЗОЛИРОВАННЫХ срезов источника (`ffmpeg -ss … -t …`), не финального микса (там Русский вокал + бит топят English-хук, `language="en"` даёт мусор).
- **⚠️⚠️ auto-`[pingpong]` НАКЛАДЫВАЛ вокалы вместо чередования (два бага в `build_pingpong`).** Юзер: «они вместе играют, никакой не по очереди; один ускоренный, потом пропадает». Причина 1: `segment_phrases` на рэпе (нет пауз >0.35с) выдаёт 1-2 ГИГАНТСКИЕ фразы по 15-31с на источник, а старый код ставил их с шагом `phrase_beats` (~2.2с) → 30с-фраза A ещё играет, когда B стартует через 2.2с → тотальное наложение. Причина 2: фраз всего ~4 → оба индекса исчерпываются к ~44с, дальше ТИШИНА до конца (122с). «Ускоренный» = chipmunk `pitch_prob` на разбросанных фразах + stutter. **Фикс:** (а) `chunk_phrases` рубит длинные пассажи на чанки ≤`phrase_beats` (+дроп тихих/<0.12с) → ~22 фразы/источник; (б) таймлайн двигается на РЕАЛЬНУЮ длину фразы, квантованную вверх до слота (`beat += ceil(dur/step)*step`) — следующая фраза НИКОГДА не наложится (питч-slow, ставший длиннее слота, берёт 2 слота); (в) убран рандомный «−15% overlap nudge». Результат: 45 фраз, 0 наложений, оба голоса в КАЖДОМ 15с-бакете 8→106с. Регресс-тесты `pingpong_phrases_never_overlap` + `pingpong_keeps_both_voices_to_the_end` (непрерывные source-тоны = rap-случай). Диагностика: `SDSP_DEBUG_PINGPONG=1` печатает план (голос/beat/at-sec/dur/pitch) — sample-точная карта «кто когда».
- **Pingpong для рэпа: `pitch_prob=0`** (chipmunk-питч звучит как баг «ускоренный вокал» на читке — не электронный чоп), `loop_prob≈0.15` (stutter — ок, in-slot, hip-hop). `phrase_beats=4` = смена рэпера каждый такт. Проверка на выходе: kx cross-corr окон выхода с сухими вокалами (агрегат «оба присутствуют / никто не пропал»; per-window «кто» ненадёжен — рэп-голоса спектрально похожи, нормировку корреляции легко получить >1).
- **⚠️⚠️ «0 наложений» ≠ «не каша» — timing-корректность и музыкальность среза это РАЗНЫЕ оси.** После фикса overlap юзер всё равно слышал «наложения/кашу»: 73%/71% фраз резались РОВНО по потолку `phrase_beats` (chunker никогда не находил паузу) → разрез посреди слова, ~67% «горячих хвостов» (RMS последних 35мс в пределах −6дБ от медианы фразы = обрубленное слово), медианный гэп между репликами 0мс → два похожих рэп-тембра впритык сливаются в рваный шум. **Фикс (v2.4, всё в `build_pingpong`/`chunk_phrases`):** (1) **dip-cut** — в окне [max/2, max] ищется минимум 30мс-RMS (скан 5мс); принимается если ≥6дБ ниже медианы окна (реальная межсловная пауза, короче 0.2с-порога `segment_phrases`), иначе fallback жёсткий срез; (2) **breath-gap** `gap_ms` (дефолт 150) резервируется в КАЖДОМ слоте: `chunk_max = slot − gap`, stutter_fill тоже заполняет только до chunk_max — ухо успевает зарегистрировать передачу слова; (3) **перцептивное разделение голосов**: `voice_pan` 0.18 (A чуть влево, B вправо, balance law) + `voice_tilt_db` ±1дБ high-shelf @5k (A темнее, B ярче); (4) `throw_prob` (дефолт 0) — мягкий dub-throw fb 0.35, хвост НЕ двигает грид (advance по сухой длине); для плотного рэпа держать 0. Результат: at-ceiling 73/71% → 12/21%, hot tails 67% → 32%, все гэпы ≥150мс, overlaps по-прежнему 0. Тесты: `chunk_cuts_at_energy_dip_not_at_ceiling`, `pingpong_leaves_breath_between_turns`, `pingpong_splits_voices_in_stereo`.
- **⚠️ `end_beat` в `[pingpong]` обязателен** — без него диалог кладёт фразы, пока не кончатся ОБА источника, и вокал переживает бит (dip-cut ест источник медленнее → 61 слот вместо 45 → 19с акапеллы над тишиной в конце). Считать: `end_beat ≈ (len_sec_бита × tempo_ratio) / spb − 4-6 тактов` (Power 122с×0.99=120.8с=такт 221 → 216; Jump 118×0.9715=114.6с=210 → 204).
- **Диагностика нарезки:** `SDSP_DEBUG_PINGPONG=1` печатает и `src [s0..s1]` — скрипт `scratchpad/pp_metrics.py` считает at-ceiling %, гэпы, hot tails по сухим исходникам. Мерять ДО/ПОСЛЕ любой правки сегментации.
- **TP-замечание:** лимитер держит sample peak ровно на ceiling (−1.0), но ebur128 true peak показывает +0.1..0.2 dBFS — межсэмпловый овершут за пределами 4× TP-детектора на сильно зажатом мастере. Существовало до v2.4, не регресс.
- **Структура «лид + хук-бридж» — альтернатива pingpong (юзер: рубленый диалог по фразам звучит неестественно при ЛЮБОЙ чистке).** Один рэпер ведёт НЕПРЕРЫВНЫМИ кусками (30с+), второй входит зацикленным хуком между ними — как фит-артист, не диалог. Рецепт: лид = `[[track]] role="vocal"` (offset_beats + start_sec/len_sec — получает HP+comp, чего `[[phrase]]`-стемы НЕ получают), хук = `[[source]]`+`[[phrase]]` с `loops=3-4` + `throw=true` (эхо-хвост всей петли в конце бриджа). Без секций — top-level tracks + phrases на одном глобальном гриде. Пример: `tools/sdsp-mash/lead_bridge_babys.toml` (Организация лид × Detsl хук × Baby's).
- **Loop-юнит хука резать «от онсета до онсета следующего повтора»** (не «от начала слова до конца хвоста») — тогда петля seamless по построению: атака следующего повтора маскирует шов (замерено: |dx| на швах 0.06 при глобальном 1.74, щелчков нет). Юнит подгонять к целым долям: у Detsl «Не важно, кто там у руля и не важно…» = 4.38с = ровно 8 долей @110. Аутро-повторы трека — чистейший источник (хук в изоляции); whisper-тайминги сверять RMS-сканом, онсет бывает на 20-40мс раньше whisper.
- **Лид-вокал НЕ стретчить = грид ОБЯЗАН быть равен native BPM лида** (иначе несинхрон копится: 110.06 на гриде 108 разъезжается на 0.57с за 30с куска). Бит тянуть к вокалу: +4% ускорение Baby's 105.71→110 звучит нормально (урок «>5-6% убивает грув» — про замедление). One-shot/loop источники — `tempo_ratio=1.0` всегда (стретч сдвинул бы фразовые start_sec; дрейф петли 16мс/повтор неслышим, куплеты кладутся на грид заново — дрейф не копится).
- **Шов «конец куплета | старт куплета» в непрерывном рэпе бывает всего −36дБ/30мс** (Организация «осовь. | Мы,» на 144.27) — это валидная точка разреза для EDL, micro-fade 22мс скрывает. Не искать «настоящую тишину» там, где её нет.
- **⚠️ «Жидкий» переход vs «мощный» — две причины.** (1) БАГ ПОРЯДКА FX: `apply_all` сортировал только по start → beat_repeat (start позже) ПЕРЕЗАПИСЫВАЛ хвост riser'а (start раньше) — свелл стирался, оставался ровный шум середины (замерено: RMS верхушки riser'а 0.08 вместо 0.25). Фикс: два прохода — rewrite/shape (tape_stop, beat_repeat, filter_sweep, hp_sweep, kick_pump) сначала, аддитивные (riser, sub_drop, echo_out) после, каждый проход по start. Тест `additive_fx_survive_rewrites`. (2) Рецепт мощного перехода в бридж: riser 2 такта (150→16k, peak 0.65) + beat_repeat последнего такта + **filter_sweep-close 16k→350 последних 2 долей** (мьютит верха бита, riser поверх орёт один — «закрыто→открыто») + sub_drop 58→40Гц, peak 0.9, len 3 на даунбит. Метрика «мощности»: lift = RMS(1-я доля бриджа) − RMS(последняя доля куплета): было +3.0 → стало +6.7 дБ; провал перед дропом (−9 дБ на закрытой доле) — это фича-контраст, не баг.
- **Эскалация лупа: `loop_gain_step_db` на `[[phrase]]`** (повтор k играет на k·step дБ громче; тест `edl_loop_gain_step_escalates`). Хук ×4 со step 1.0 = финальный повтор +3 дБ — вокал на −3 LU под битом поднимается ДО бита, слышно без «орёт». `throw` применяется ПОСЛЕ repeat → эхо-хвост сидит на самом громком повторе (бесплатный бонус эскалации). На пик последнего повтора класть свой sub_drop (peak 0.8).
- **⚠️ Бит-стем длиннее финала = антиклимакс.** len_sec бита обязан кончаться РОВНО на конце tape_stop (`len_sec = t_stop_end / tempo_ratio`), иначе после «финала» голый бит играет ещё N секунд и тупо обрывается микрофейдом (здесь было +5с). RMS-скан ловит мгновенно: после стопа −5 дБ ровного бита вместо затухания.
- **Финал «улетает», а не обрывается:** tape_stop + filter_sweep 16k→250 ОДНОВРЕМЕННО (одинаковый at_beat; tape_stop раньше в файле → фильтр красит уже остановленную ленту = темп и тембр умирают вместе) + echo_out с `at_beat = stop + 2 доли` — эхо читает УЖЕ замедляющуюся ленту (dub-пульс, не маскирует сам pitch-drop). Feedback подбирать под остаток буфера: fb 0.65 не успевал затухнуть (обрыв на −9 дБ), fb 0.5 → хвост −6.8/−16 дБ к концу. Буфер за стопом даёт throw-хвост бриджа (~5с) — echo_out живёт в нём.

- **LRA лечится ПРЕМАСТЕРОМ, не мастером:** если всё бьётся в потолок лимитера, drop-lift ≈ 0 и LRA ~2 — опустить ВЕСЬ не-дроповый премастер на 3-6дБ (вокал ВМЕСТЕ с битом, соотношение рецепта сохраняется), компенсировать input лимитера. Дошло 2.2→4.5 LU без потери клубной громкости. Проверка кривой: intro ≈ −16, куплеты ≈ −10, breakdown ≈ −13..−15, дроп ≈ −8.5, drop-lift ≥ +1.
- **Тихие spoken one-shots проверять A/B-дифом рендеров, НЕ кросс-корреляцией:** [pump]-модуляция + мастер-цепь рвут norm-corr на слабом SNR (corr 0.05 при реально присутствующей фразе). Рендер с gain −60 на фразе → diff RMS в окне = точный уровень фразы в миксе (движок детерминирован). Так же меряется «на сколько дБ под миксом сидит крик» (интро-крик Disturbed сидел −8.6дБ → поднят +5).
- **Spoken-интро в вокал-стеме бывает на 10-12дБ тише куплетов** (Dragula «Superstition» −33.7 vs куплет −22; Manson шёпот-куплет тоже) — one-shot тизеры компенсировать гейном +8..+13, и НЕ класть их внутрь intro_sweep (HP-фильтр съедает речь) и не вешать sub_drop прямо НА слово (грязь + рвёт верификацию) — sub на возврат бита, тизер в гэп.
- **Stop-time гэп 1.5 доли под финальный тизер:** сплит дроп-бита на два блока (…→210.5 и 212→конец), фраза начинает соло в дыре, бит слэмится обратно под её хвост + sub_drop на возврат. Дешёвый «холодок» перед tape_stop.
- **Куплет-рубато без нативных драмов (Manson verse 1) не воюет с гридом:** класть его над тонкой подложкой БЕЗ наших драмов (как в оригинальной аранжировке — барабаны входят на хуке), по-строчно на 8-битовые слоты; дрейф над рифом неслышим. Разрез строки — по вдоху (70мс dip на RMS-профиле, у Manson 33.05).
- **⚠️⚠️ Метрика транзиентов НЕ ловит «звучит замедленно» — Baby's −12.8% ОТКЛОНЁН юзером.** WSOLA-транзиенты были чистые (top-rise 9.2 vs 10.1 native, peak/RMS одинаковый), но юзер удалил файл: знакомый бит, замедленный >10%, читается как «тянучка» даже без артефактов — метрика меряет размазанность, не perceived-феел. ПРАВИЛО: тяжёлое замедление (>6-8%) УЗНАВАЕМОГО бита — только при чистом BPM-отношении/встречном стретче; если пара его не даёт — менять бит, не давить стретчем. Ускорение прощается легче замедления (+15% Serial Thrilla прошёл, +21% Firestarter прошёл).
- **Изолированная транскрипция срезов обязательна для метала:** полностековый whisper на Disturbed пропустил ПЕРВЫЙ гига-припев (91-117с) целиком и слышал культовый крик как «Ah shit»; на Manson галлюцинировал аутро-строку в тишине (−80дБ) и запорол зону криков. RMS-карта вокал-стема (1-4с окна) → зоны → `ffmpeg -ss/-t + loudnorm` → whisper по срезу. Самый горячий 1с-пик карты = кандидат на «крик-акцент» (Disturbed 275.2с −9.8дБ).
- **Не-дроповый эксплицит-бридж (Disturbed «mommy» 190-245) пропускать сознательно** — его даже радио-эдиты режут; драматургии он не нужен, дыра закрывается нативным бриджем «woken up the demon → THE ENEMY!», который сам летит в припев.

- **Петлевая техно-структура для живого кубыза (2026-07-17): один мотив вместо куплет-припева.** Задача «бэкинг под живой кубыз» ≠ мэшап — нужен ОДИН континуальный тейк бита (drums+bass+other, 64с из уже-лупового high-energy зоны трека, взято прямо из `analyze`-структуры без ре-нарезки) + ОДИН короткий вокальный чоп (~1-1.5с), который ретриггерится через `[[phrase]] loops=N loop_gain_step_db=X` 3-4 волнами по нарастающей (loops/gain_db/`throw`) — а не разные строки куплета. `[breath]`(every_bars=8) даёт периодически «открывающийся» фильтр, `[pump]` — дыхание грува. Дешевле и честнее жанру (техно-трек развивается повтором, не рассказом).
- **Chop+retrigger вместо WSOLA на коротких хайповых фразах — обходит баг «звучит замедленно».** Для фразы 1-4 слова BPM-стретч не нужен вообще: вырезать one-shot (`tempo_ratio` не ставить, дефолт 1.0), положить на грид БИТА через `at_beat` в `[[phrase]]`. Родной BPM вокала (тут Организация 111.90, Агент 161.18 псевдо-октава ~110-семьи, Detsl 111.05) станет нерелевантен — стаб короче одного бита бита-хоста, склеек/растяжки не слышно. Разница с полноценным лид-вокалом (line 81): там грид ОБЯЗАН = BPM вокала; здесь — не важно.
- **RMS breath-dip скан для чистой границы фразы без whisper.** Скрипт (`numpy`+`soundfile`, 40мс потом 10мс окно) находит вход в фразу (быстрый подъём из провала ≥−40дБ) и следующий провал — режет onset-to-onset без транскрипции. На плотном рэпе (Oxxxymiron, дискретных пауз почти нет) вменяемая длина фразы 1-1.5с между двумя ЛОКАЛЬНО-глубочайшими провалами (не любыми, там полно мелких -20дБ синтаксических пауз).
- **Detsl «Кто там у руля» hook loop-unit ПЕРЕИСПОЛЬЗУЕМ между конфигами** (140.44-144.83с, 4.38с, уже валидирован в `lead_bridge_babys.toml` — не искать заново, если трек/куплет тот же).
- **⚠️ В `tools/sdsp-mash/` уже лежали `kubyz_trial_higher/doppler/monument.toml`** — другая ветка идеи («бит + ЗАПИСАННЫЙ кубыз-сэмпл» из `~/Music/SuperDuper Samples/kubiz-bash/`), не мэшап с рэп-вокалом. Не путать: если юзер хочет живой кубыз поверх — рэп-чопы (этот заход); если хочет бэкинг с уже сыгранным кубызом как сэмплом — та ветка (не рендерилась, черновик).
- Пары этого захода: SMBU chorus(253-317с)×Detsl hook (136.19, LUFS −10.2/LRA 1.4), Amelie Lens Higher(20-84с)×Организация-стаб (135.98, −11.1/LRA 6.0, самый «пулемётный»), Monument Barnt(120.8-184.8с)×Агент-стаб (125.11, −11.0/LRA 3.0, самый медитативный).

- **Формат «гипно-луп» (2026-07-17, для кубыз-сета):** техно-бит в тонике кубыза (A#) + КОРОТКИЕ зацикленные рэп-фразы вместо куплетов (смысл от повтора). Механика: юнит режется до РОВНО N грид-битов (фраза + воздух; `loops=K` кладёт повторы встык → грид-лок by construction), `loop_gain_step_db` 0.7-1.0 = развитие, волны лупов на 48/72/128/168, breakdown = длинная фраза почти соло, стаб после tape_stop. Word-timestamps русского рэпа уже лежат в `scratchpad/wx_*/vocals.json` (карaоke-сессии) — не транскрибировать заново. Фразы-([[phrase]])-лупы НЕ получают vocal-цепочку → гейн на +2дБ выше, чем интуиция от [[track]]-вокала. Конфиги: `hypno_smbu_organizatsiya` / `hypno_higher_detsl` / `hypno_doppler_zaverbovan` (LRA 4.9-6.5).

- **Yukimatsu-style сет (2026-07-17): 5-10 независимых мешап-частей вместо одного мегамикса, собранные ffmpeg acrossfade поверх уже принятых sdsp-mash рендеров.** Техника (найдена реверс-инжинирингом реального сета): (1) темп-буст +2-7% почти на каждом треке (у нас уже естественно получается через «тянуть бит к вокалу»), пара треков БЕЗ буста — ок для контраста; (2) БИМОДАЛЬНЫЕ переходы: либо жёсткий cut (`acrossfade=d=0.05` — не 0, иначе щелчок на стыке разной фазы/DC), либо долгий blend (`acrossfade=d=35..45:c1=qsin:c2=qsin` — qsin ближе к equal-power, чем дефолтный tri, меньше «яма» в середине перехода); НИКАКИХ переходов 15-20с (та самая «средняя зона», которую техника прямо избегает); (3) атмосферный безбитовый мост-пауза 20-65с 1-2 раза за сет — искать в исходниках готовый беззвуковой/безбитовый пассаж (интро/аутро), а не городить с нуля; (4) жанровый эклектизм осознанно (диско/рок/рэп/техно подряд); (5) дуга: умеренно-эклектичный старт → стабильная середина с 1-2 намеренными просадками → техно/dnb пик (собрать из НЕСКОЛЬКИХ частей подряд — тогда он естественно «держится дольше» остальных) → антемный финал (искать в библиотеке готовые finale-конфиги с tape_stop/sweep).
- **⚠️⚠️ Собранные ffmpeg `acrossfade` из двух УЖЕ отлимиченных (-2дБТП) файлов легко даёт true-peak овершут +0.3…+1.0 dBFS** на пике перехода (сумма фаз в overlap-окне) — ловится ТОЛЬКО замером готового файла, не видно по исходникам. **`ffmpeg alimiter` — НЕПРАВИЛЬНЫЙ фикс**: это maximizer (тянет уровень К потолку), с `asc=1` или без — только УХУДШАЕТ true-peak и поднимает LUFS вместо того чтобы просто подрезать транзиент (проверено эмпирически: limit=0.891→Peak +0.3, limit=0.708→Peak +1.0 — чем ниже ceiling, тем ХУЖE, потому что это лауднесс-максимайзер, не safety-лимитер). **Правильный фикс — плоский `volume=-1.5…-2.5dB`** на весь смонтированный кусок ПОСЛЕ acrossfade, затем перепроверить ebur128 — без всякой доп. динамики, только gain trim.
- **⚠️ Найден и починен систематический баг громкости в 6 старых конфигах** (`pingpong_jump/power.toml`, `example.toml`, `lead_bridge_babys.toml`, `miniset_smbu.toml`, `miniset_kino.toml`) — все datированы ДО фикса loudness-метра (см. v2.5 запись выше), лимитер стоял на старом рецепте (input 6.0-12.5 / ceiling -1.0), что реально даёт -6.7…-8.4 LUFS и sample-peak до +0.7 dBFS (клип). **Симптом для будущего поиска**: `grep -n 'plugin = "limiter"' -A1 *.toml` → любой `params` с `"0"` (input) выше ~5.0 и `"1"` (ceiling) = -1.0 — подозрительный, почти наверняка датируется до фикса. Лечение: `input≈2.8, ceiling≈-2.8`, перерендерить тем же биндарём (движок уже пофикшен, дело только в конфиге) — все 6 переехали в -9.3…-13.8 LUFS / -1.9…-2.2 dBTP диапазон.
- **Готовый атмосферный мост находится ЧАЩЕ ВСЕГО в самом исходнике, не строится с нуля**: у Bowie «Space Oddity» drums-стем показывает energy 0.00-0.06 почти всю первую 79 секунд (культовое интро «Ground Control to Major Tom» реально безбитовое) + отдельная настоящая тишина 266-309с (35с, аутро-фейд) — то и другое готовые 20-65с безбитовые пассажи, бери `analyze` на drums-стем И vocals-стем, ищи зоны energy≈0 на ОБОИХ.
- **Donna Summer "I Feel Love" — почти идеальный disco-в-техно мостик**: 125.76 BPM, ОДНА непрерывная 130-секундная "chorus"-зона energy 1.00 (диско-пульс уже гипнотичен как техно-петля, ничего не нужно перезацикливать) — просто взять контурным куском, +3-4% темп-буст в сторону клубного темпа (130) укладывается в ±5% вокальный допуск (её партия тоже тянется вместе с битом, единая стретч-пропорция, не кросс-трек рассинхрон).
- **`[[master]]` в sdsp-mash НЕ включает reverb/delay/chorus** (в отличие от sdsp-chain, у которого 12 статик-слинкованных плагинов) — только `eq, lineq, compressor, saturator, limiter, midside, filter` (см. `SUPPORTED` в `src/chain.rs`). Для «пространства» на атмосферных кусках — только timeline-эффекты `echo_out`(несколько с разными delay_ms/feedback) + `filter_sweep`, реальной хвостовой реверберации нет.

## Правило живого скилла

После каждой сессии мэшапов: новые приёмы, грабли и удачные пары дописывать сюда же (секция «Уроки»).
- v3-идея (подсмотрено у betonmixer.app): **дабл-дроп выравнивание** — совмещать не такты, а ДРОПЫ двух треков (detect по всплеску энергии после ямы из structure/beats), фейды строить от точки дропа назад. Также их фишка «замена трека пересчитывает весь микс» = наш декларативный TOML.
- **Реплика чужого DJ-сета — 3 грабли, все нашлись при попытке повторить Yukimatsu (Coachella 2026):**
  1. **`[[section]]` в MashConfig умеет мульти-трековую секвенцию с секционным bpm** — не только 2-трековый мэшап. Трюк: `bpm=60` глобально → 1 beat = 1 сек ровно, `xfade_beats`/`lead_out_beats` читаются как обычные секунды, `start_sec` на каждой секции ставит абсолютную позицию без пересчёта битов. `transition` на секции триггерит и fade, и entry/lead-out FX (`cut`→beat_repeat+filter-close+echo, `breakdown`→растянутый filter-close, `filter_sweep`→открывающий EQ на входе) — качественно лучше голого ffmpeg-кроссфейда, это и просил юзер («не топорно, через модуль»).
  2. **Никогда не забывай `[[master]]`** — без него сырой микс легко улетает за +3 dBTP просто от каскада кроссфейдов (уровень копится). Рецепт этой ночи: eq(params 7=30,1=1.5,5=7000,6=2.5) → compressor(0=-16,1=2,2=30,3=200,5=2) → limiter(0=3.1,1=-2.8).
  3. **`balance_sections=true` (дефолт) выравнивает по RMS с дедбендом ±4.5дБ — но не ловит явные грубые расхождения**, если они в пределах дедбенда по RMS (просадка/пик может быть чисто спектральная/тональная, не RMS). Раздельные исходники DJ-сета могут отличаться по мастерингу НА 15-19 ДБ (реальный кейс: один трек через loudness-war мастер −6…−10 LUFS, другой — дэнс-альбом 2001 года −26 LUFS) — сверяй `ffmpeg ebur128` по каждому исходнику ПЕРЕД сборкой, не только результат, и клади ручной `gain_db`/`comp` на аутлайеры.
  4. **Не бери исходник с 0:00** — реальный диджей режет с содержательной точки (риф/хук/билд), не с начала файла. Найти реальную точку входа: вырезать сегмент из ИЗВЕСТНОГО чужого микса (по таймкодам), посчитать chroma (`librosa.feature.chroma_cqt`) и по нему, а не по сырому сэмплу, sliding-window cosine-match против ПОЛНОГО исходника — устойчиво к небольшой разнице темпа. `scratchpad/yuki_replica/find_offset.py` — рабочий шаблон.
  5. **Новый FX: `backspin`** (`kind="backspin"` в `[[fx]]`) — реверс-чтение региона от хвоста к началу с реверс-рейтом 0.3×→3.0× (аналог `tape_stop`, но назад и ускоряясь, а не вперёд-и-замедляясь). Даёт классический виниловый бэкспин-скретч. Пока НЕ подключен как `section.transition` (только явный `[[fx]]`) — если понадобится как тип перехода, дописать в `apply_section_transitions` по аналогии с `cut`.
