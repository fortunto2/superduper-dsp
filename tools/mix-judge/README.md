# mix-judge — оценка обработки звука без ушей

Судья для конкурса, где участники присылают **программу**, а не аудиофайл.

## Схема

У судьи есть эталон `M`. Он применяет известную порчу `D` (наклон спектра,
пережатие, сужение стерео; параметры от seed) и раздаёт `D(M)`. Участник
возвращает `R(D(M))`. Балл — расстояние до `M`.

Ground truth однозначен, вкус не участвует. Подгонка под метрику ломается
скрытым тестовым набором и случайным seed.

## Оценка: пять осей в единицах бездействия

`1.0` = не тронул · `0` = попал в эталон · `>1` = сделал хуже, чем было.

Веса не нужны: каждая ось нормируется на собственную порчу. Первая версия
считала одно число со взятыми с потолка весами и провалилась — починка
«в минус» получала балл лучше бездействия, потому что ось динамики забивала
остальные.

| ось | что ловит |
|---|---|
| `спектр` | мультиразрешающее лог-спектральное расстояние (FFT 512/2048/8192) |
| `баланс` | худшее отклонение по пяти полосам, dB |
| `динамика` | разница крест-фактора, dB |
| `стерео` | разница ширины (side/mid) |
| `содержание` | 1 − пик взаимной корреляции по окнам 250 мс, допуск сдвига ±50 мс |

## Gate плюс балл, а не одно число

`худшая_ось` — **gate**: ухудшил что-то в полтора раза, не участвуешь, сколько
бы ни выиграл в другом. `ИТОГ` (среднее) ранжирует только прошедших.

Обе крайности проверены и обе плохи. Просто среднее — тайные равные веса:
карикатура с осью содержания 50.6 тонет в нём до 11.0. Просто максимум
заваливает честную починку, которая улучшила три оси и на 22% ухудшила
четвёртую.

```

эталон сам с собой        0.014   0.071     OK    0.071  0.000  0.000

починил В МИНУС           1.103   1.836   СТОП    1.163  1.067  0.682
```

## Задержка обработки не штрафуется

Identity/pass-through обязан давать ровно 1.000. В памяти и через WAV он это
и давал — пока в него не добавили **честную задержку**, которая есть у любой
FFT-цепочки. Судья наказывал за 23 мс на 9%, а на 93 мс ось содержания
улетала в 42.9, выйдя за собственный допуск ±50 мс:

```
сдвиг            спектр   содержание        после починки: спектр  содержание
1024 (23 мс)     1.0927       1.0318                       1.0002      1.0000
4096 (93 мс)     1.1689      42.8756                       1.0013      1.0000
```

Лаг ищется кросс-корреляцией огибающих в пределах ±0.5 с, снимается перед
оценкой и возвращается в отчёте полем `задержка_смп` — скрывать её молча
нельзя. Выравнивание проверено на том, что оно **не** спасает карикатуру
(50.6) и шум (67.8): обе по-прежнему не проходят gate.

Непроверенное место: дробный лаг округляется до целого сэмпла. Stranger-check
на чужой реализации (C++ pass-through, postingboard) это и должен нащупать.

## Три атаки с доски, и что с ними стало

1. **Карикатура** (quiet-visitor-5302): сохранить спектр эталона, уничтожить
   содержание случайными фазами. До пятой оси получала **1.072** при
   корреляции с эталоном **0.02** — судья отличал шум-с-правильным-спектром
   от честного бездействия на 7%. **Закрыта**: ось содержания даёт 50.602.
   Фазы рандомизируются в mid/side раздельно, иначе атака выдаёт себя
   осью стерео (35.4) и выглядит пойманной по случайной причине.
2. **Обращение порчи** (quiet-visitor-5302, wedoit): участник знает
   *семейство* D и обращает его, эталона не видя. Берёт **0.354**, а по
   спектру/динамике 0.31 и 0.02. **Не закрыта и метрикой не закрывается** —
   лечится только порчей вне семейства в скрытом наборе. Публиковать этот
   результат как потолок: кто не побил D⁻¹, тот ничего не показал.
3. **Произвольный код на машине судьи** (quiet-visitor-5302): артефакт
   участника может прочитать эталон. Архитектурное, не метрическое:
   запускать без доступа к M и к скрытому набору.

## Чего не умеет

Ловит грубое: перекошенный спектр, задавленную динамику, схлопнутое стерео.
**Вкус не ловит.** Микс, технически более близкий к эталону, может звучать
хуже. Для творческой части нужны люди, слушающие вслепую.

Обсуждение и критика схемы: getpostingboard.dev, топик `music`.

## outfamily.py — порча вне семейства не закрывает дыру читера

Проверка предложения с доски: добавить к семейству порчу, которая через него
не выражается (ранние отражения 7–47 мс + мягкий клип), чтобы обращение
известных параметров перестало работать.

```
                              v1 (семейство)   v2 (+реверб и клип)
агрессивный читер             0.354 прошёл     4.133 ОТСЕЧЁН
аккуратный читер              0.396 прошёл     0.546 ПРОШЁЛ
```

Первый прогон выглядел как успех: 4.133 и gate сработал. Но 18.340 в той
строке — ось **стерео**: читер расширял стерео вслепую, реверб сделал каналы
непохожими, и расширение раздуло расхождение. Он отсёкся за неаккуратность,
не за неспособность снять порчу. Читер, не трогающий стерео, проходит и на v2.

Реверб и клип не мешают снять наклон и пережатие — они портят **другие** оси
(содержание 1.177), а спектр 0.605 и динамику 0.033 читер забирает целиком.
Правило: порча вне семейства помогает, только если бьёт по тем же осям,
которые читер чинит. Иначе это вторая задача рядом с первой.

Контроль решаемости: эталон против v2 даёт 0.003.

## broke_repro.py — воспроизведение первого провала

Отдельный самодостаточный скрипт: реализует **обе** версии метрики,
сломанную и нынешнюю, на синтетическом сигнале с фиксированным seed.
Печатает строку `провал воспроизведён: True/False` — то есть сам сообщает,
подтвердилось ли утверждение, а не оставляет это на веру читателю.

```bash
uv run --with numpy --with scipy python broke_repro.py
```

Первая версия метрики переворачивала порядок целиком:

```
ничего не делать        20.091
починил правильно       22.219   <- худший
починил В МИНУС         17.590   <- лучший
```

Скрипт печатает и то, чего починка **не** закрыла: когда участник не
трогает доминирующую часть порчи, обе версии ранжируют неверно, потому что
наклон в минус случайно приближает крест-фактор к эталонному. Честная
граница судьи — отличать сделанное от несделанного, а не сравнивать двух
одинаково половинчатых участников.
